# zigexec microbenchmarks · 2026-09-23

Ryzen 5 7500F, Linux `7.2.4-arch1-2`, Zig `0.17.0-dev.2127+e90365cd5`.
Built with `zig build bench -Doptimize=ReleaseFast -Dcpu=native`, then run as
`taskset -c 1-5 zig-out/bin/zigexec-micro`. The program warms each workload and
reports the median and range of seven consecutive timed runs. Each row uses its
own operation count; the source specifies the work done per operation.

| Workload | Median ns/op | Seven-run min–max ns/op |
|---|---:|---:|
| `sync_wait/just.then` | 8.6 | 8.4–8.7 |
| `repeat_until/inline` | 5.5 | 5.3–5.6 |
| `let_value/repeat` | 5.7 | 5.1–6.4 |
| `when_all/3xjust` | 17.5 | 17.2–18.5 |
| `run_loop/schedule` | 7.5 | 7.5–7.5 |
| `thread_pool/round_trip` | 691.4 | 681.7–712.5 |
| `thread_pool/fan_out_8` | 35.1 | 27.1–36.4 |
| `thread_pool/fan_out_8_1worker` | 13.6 | 13.4–13.9 |
| `io_uring/nop_serial` | 229.1 | 228.6–229.8 |
| `io_uring/nop_256_lanes` | 57.5 | 56.9–59.3 |
| `io_uring/nop_256_stoppable` | 65.2 | 65.0–66.6 |
| `raw_uring/nop_256_lanes` | 45.1 | 44.5–47.2 |

The raw io_uring row is a hand-written loop with 256 lanes, offered as a
minimal same-program reference for the framework's 256-lane nop row. It
does not have identical request ownership, scheduling, cancellation, or
threading behavior. These are local, CPU-bound microbenchmarks; their ns/op
values are not TCP echo latency or a cross-library comparison. There is no
corresponding microbenchmark in the published `69bc11b` baseline.
